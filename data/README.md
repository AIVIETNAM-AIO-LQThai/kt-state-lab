# Data

Raw student data is **not** committed. Put acquired files under `data/raw/`
(gitignored) and keep `data/README.md` for access notes only.

Canonical input file name: `<dataset>_<version>.csv`, for example
`assistments_2009.csv`. The CSV must follow the contract in
`docs/protocols/cs_s_splits.md`.

Do not paste raw rows, student identifiers, or screenshots of student data into
issues, notebooks, or dataset cards. Record checksums and aggregate counts
instead.
